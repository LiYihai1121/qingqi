跳过结局诊断（漏跳 / 误拦）

建议新增 · 合成演示
P0 核心：skip_outcome 把「只记成功」扩展为 matched / unmatched / blocked 三分结局。目前漏跳与护栏拦截零遥测。

激活漏斗

建议新增 · 合成演示
P1：安装 → 生效的 6 步转化。除转化率外还看每步中位耗时——「转化了但花了 7 分钟」同样是严重体验问题。

设备留存曲线

建议新增 · 合成演示
P1：无账号体系，故以「设备」为单位。需用 svc_lifecycle 做「有效留存」，纯 app_open 会严重低估（用户不开 App 但服务在跑，其实用得好）。

页面浏览与停留

建议新增 · 合成演示
P1：screen_view / screen_exit 配对算停留。用途是识别困惑——设置页停留过长 + 反复进出 = 配置看不懂。

异常操作路径

建议新增 · 合成演示
P2 路径分析：识别「异常绕行」与「死路」——用户其实在怀疑功能是否工作，或在配置上卡住。
