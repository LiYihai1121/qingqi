# 轻启客户端当前 UI 设计

> 2026-10-29 · 本轮实现与交互原型。未进行 Android 真机视觉验收。
> 代码颜色事实源：`ui/theme/Color.kt`；本文件不复制色值表。

## 产品与导航

底部导航为首页 / 记录 / 规则 / 设置，应用管理从首页进入。保留已有能力和存储协议，不增加账号、会员或云端能力。当前品牌以 #198 合并的绿色为准；旧蓝色 v4 文档仅为历史。

- 首页：状态卡、权限入口、使用概览、快捷入口、模拟测试、原理说明。三态为运行中 / 未开启 / 无法确认；未知态用信息图标与明确文字，不能假装已关闭。统计标题为使用概览，累计值不标为今日。
- 权限入口：设置导航行，点击进入系统设置并在 ON_RESUME 重查。只有应用自己的布尔设置才用开关。
- 记录：使用全局主题，保留范围筛选、分享、清空确认与撤销；不强制单页深色。
- 规则：搜索、内置来源标签、添加与删除撤销；沿用现有 ViewModel 校验。
- 应用管理：搜索、启用筛选、独立应用开关，保持业务含义不变。
- 设置：索引打开单独详情视图，顶部与系统返回都回索引；详情状态可保存，切换详情回到列表顶部，复用同一个 SettingsViewModel。同步分组改为“同步与高级设置”，准确覆盖现有运行配置。
- 引导：单屏解释用途，随后进入首页授权；没有虚假页码，深浅色统一取主题。

## 组件与适配

容器以色阶、留白分组，卡片无阴影；中等圆角 20dp、大圆角 24dp。搜索框最小 56dp，分段选择最小 48dp，随字体扩展高度；分段使用 selectable / selectableGroup，读屏获知选中状态。图标继续使用项目 AdSkipIcons，避免引入第二套图标依赖。

## 浏览器预览的边界

`docs/diagrams/ui-preview-v4.html` 保留路径以兼容旧链接，内容已替换为绿色交互原型。包含六个主视图与设置详情，支持主题、三态、空列表、搜索、添加、删除撤销、清空确认。示例数据仅在内存中，不连接服务端，不修改 Android 权限。

浏览器是流程和视觉方向原型，不是 Compose 像素截图。原生保留真实统计的最近应用、所有权限条目和高级配置；原型使用简化演示。正式验收仍需 Android 字体缩放、窄屏、横屏与读屏测试。不得把浏览器检查当作原生视觉验收。

## 依据与验证

采用 Material 3 的分组、导航与颜色角色思想，不照搬某个品牌页面：
- https://m3.material.io/components/navigation-bar/overview
- https://developer.android.com/guide/topics/ui/accessibility/views/apps-views

执行 `ktlintCheck`、`assembleDebug`、`testDebugUnitTest`；浏览器验证导航、关键词增删与撤销、搜索、清空撤销、详情返回、主题与移动端溢出。具体结果以本次交接说明为准。
